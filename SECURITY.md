# Security / Segurança

**Reporting a vulnerability:** please use GitHub's private vulnerability reporting ("Report a vulnerability" in the
repository's *Security* tab) instead of a public issue. Describe the problem, how to reproduce it and the impact.

**Never put a token, password, chat id or personal data in an issue, pull request or log you paste.** If you
leaked a Telegram bot token, revoke it in @BotFather right away.

The app is meant to listen only on `127.0.0.1`. Exposing it to a network or to the internet is outside the
supported setup.

---

**Como reportar uma falha:** use o aviso privado de vulnerabilidade do GitHub ("Report a vulnerability", na aba
*Security* do repositório) em vez de uma issue pública. Diga o problema, como reproduzir e o impacto.

**Nunca coloque token, senha, chat id ou dado pessoal numa issue, pull request ou log colado.** Se vazou um token
de bot do Telegram, revogue no @BotFather na hora.

O app foi feito para escutar só em `127.0.0.1`. Expor na rede ou na internet está fora da configuração suportada.
